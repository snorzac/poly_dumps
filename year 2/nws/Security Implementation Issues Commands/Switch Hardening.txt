Disable trunking on all switch ports except G0/0 amd G0/1 (i.e. set them to be access ports, and assume Gigabit Ethernet ports are reserved for trunk ports)
interface range f0/1-24
switchport mode access
no switchport trunk native vlan

Enable STP (Spanning Tree Protocol) PortFast mode on all switch ports except G0/0 and G0/1
interface range f0/1-24
spanning-tree portfast

Enable BPDU (Bridge Protocol Data Unit) guard on all switch access ports accept G0/0 and G0/1
interface range f0/1-24
spanning-tree bpduguard enable

Apply basic port security on all switch access ports with the following parameters
switchport port-security
switchport port-security maximum 2
switchport port-security violation shutdown
switchport port-security mac-address sticky
